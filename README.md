# MQL5 AI Copilot 📈🤖

An intelligent, web-based quantitative trading assistant that translates natural language trading logic into robust, syntax-perfect MQL5 custom indicators for MetaTrader 5.

## 🌟 Features
* **Natural Language to MQL5:** Simply describe your trading logic or indicator idea, and the AI will generate the optimized visualization code.
* **LangChain Integration:** Utilizes LangChain memory buffer and Google Gemini to maintain conversational context and ensure strictly formatted, high-quality code generation.
* **Modern Web Interface:** A sleek, minimal, dark-themed UI featuring a seamless chat experience, syntax highlighting layout, and one-click code copying.
* **Decoupled Architecture:** Clean separation between the client-side frontend and the n8n automated backend.

## 🏗️ Architecture & Tech Stack
* **Frontend:** Vanilla HTML5, CSS3, JavaScript (Asynchronous Fetch API)
* **Backend Orchestration:** [n8n](https://n8n.io/) (Node.js runtime)
* **AI Engine:** Google Gemini API (via `@n8n/n8n-nodes-langchain`)
* **Communication:** RESTful Webhooks (Production-ready with optimized CORS handling)

## ⚙️ Prerequisites
Before running this project, ensure you have the following installed:
* [Node.js and npm](https://nodejs.org/) (for running n8n locally)
* A valid Google Gemini API Key
* Python (optional, for local web serving) or VS Code with the Live Server extension

## 🚀 Installation & Setup

### 1. Backend Setup (n8n)
1. Install n8n globally via npm:
   
   npm install -g n8n

    Start the n8n server:
    

    n8n start

    Open your n8n dashboard in the browser (usually http://localhost:5678).

    Create a new workflow and build the LangChain architecture (Webhook -> AI Agent -> Window Buffer Memory & Google Gemini Model).

    Add your Google Gemini API key to the credentials section of the Language Model node.

    Ensure the Webhook node is configured to listen to POST requests on the mql5-bot path.

    Click Publish (or set to Active) to enable the Production webhook.

2. Frontend Setup

    Clone this repository or download the index.html file.

    Open index.html and ensure the webhookUrl variable in the <script> tag points to your active n8n production webhook:
    JavaScript

    const webhookUrl = 'http://localhost:5678/webhook/mql5-bot';

    Crucial Step: Do not open the HTML file directly (file:///). Serve it using a local web server to prevent Origin: null CORS issues. Using Python:
    

    python -m http.server 8000

    Open http://localhost:8000 in your web browser.

📖 How to Deploy Indicators in MT5

    Click the Copy code button on the generated script in the web app.

    Open MetaTrader 5 and press F4 to launch the MetaEditor.

    Click New > Custom Indicator and proceed through the setup wizard.

    Delete all default code generated by MetaEditor and paste the copied code.

    Press F7 to compile and ensure there are no errors.

    Return to MetaTrader 5, find your new indicator in the Navigator panel, and attach it to your chart.
