  3. In MetaEditor, click New > Custom Indicator and proceed to finish the setup (you can skip the default parameters).
  4. Delete all the default code generated by MetaEditor and Paste your copied code.
  5. Press F7 or click Compile at the top. Ensure there are zero errors in the log.
