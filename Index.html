How to Deploy & Find Data

  1. Click Copy code on the generated AI script.
  2. Open MetaTrader 5, press F4 to launch MetaEditor.
  3. Create a New > Custom Indicator, delete default code, and paste.
  4. Press F7 to compile (Zero errors required).
  5. Drag the indicator onto an active chart. It will auto-generate your signals.
  6. Locate the Data: In MetaEditor, go to the top menu File > Open Common Data Folder. Then open the Files folder to find your CSV.
  7. Upload that CSV into the Quant Dashboard for analysis!
